Healthcare Analytics:
Hospital Readmission Prediction
↗ GitHub

Analyzed 101,766 patient encounters from the UCI Diabetes 130-US Hospitals dataset to identify key drivers of 30-day hospital readmission. Built a full MySQL pipeline with data cleaning, EDA, and a 4-tier risk stratification model (Low / Medium / High / Very High) using SQL CASE logic across 9 analytical views. Designed a 4-page Power BI dashboard with KPI cards, treemaps, and patient-explorer views tailored to different stakeholder needs.

Key insight: Patients untested for HbA1c had a higher 30-day readmission rate (11.4%) than poorly controlled diabetics (9.9%) — revealing a critical screening gap in clinical workflows.
